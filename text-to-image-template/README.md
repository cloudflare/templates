Generate images based on text prompts using [Workers AI](https://developers.cloudflare.com/workers-ai/). In this example, going to the website will generate an image from the prompt "cyberpunk cat" using the `@cf/stabilityai/stable-diffusion-xl-base-1.0` model. Be patient! Your image may take a few seconds to generate.

## Getting Started

Outside of this repo, you can start a new project with this template using [C3](https://developers.cloudflare.com/pages/get-started/c3/) (the `create-cloudflare` CLI):

```bash
npm create cloudflare@latest -- --template=cloudflare/templates/text-to-image-template
```

A live public deployment of this template is available at [https://text-to-image-template.templates.workers.dev](https://text-to-image-template.templates.workers.dev)

## Setup Steps

1. Install the project dependencies with a package manager of your choice:
   ```bash
   npm install
   ```
2. Deploy the project!
   ```bash
   npx wrangler deploy
   ```
3. Monitor your worker
   ```bash
   npx wrangler tail
   ```

## Toolchain

This starter uses [Vite+](https://viteplus.dev). Use Node.js 24.22 or later in
Node.js 24, then install the dependencies with `npm install`. A global `vp`
installation is optional.

- `npm run check:toolchain` checks formatting and lint rules.
- `npm run format` formats the project.
- `npm run check` also runs this starter's existing project checks.

Use the documented development, build, and deployment scripts for this starter.
Framework commands and resource setup remain part of those scripts. Keep the
Vite alias and Vitest override aligned with the installed Vite+ release.
